# GameSage

**Your open-source AI gaming companion.**

GameSage is an open-source desktop companion designed to understand what is happening in your game and provide contextual help without forcing you to leave it.

## Current milestone

### v0.1 — See & Ask

Initial target: **The Witcher 3: Wild Hunt**

Planned first pipeline:

1. Detect the game window
2. Capture it on demand
3. Analyze the current context
4. Ask a contextual question
5. Retrieve relevant game knowledge
6. Display an answer

## Stack

- Tauri 2
- React
- TypeScript
- Rust
- Python 3.12
