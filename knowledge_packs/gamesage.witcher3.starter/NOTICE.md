# GameSage Witcher 3 Starter Knowledge

Knowledge Pack v1 — `gamesage.witcher3.starter` 1.0.0.

## Content and licensing

The five records in `corpus.jsonl` are short original summaries written for
GameSage describing widely known game facts. They are not excerpts from any
wiki. Each record's `source` block names its source and records that the
referenced Fandom (Witcher Wiki) page is CC BY-SA, while the summary text
itself is an original GameSage contribution.

This NOTICE.md exists so pack-level attribution and licensing travel with
the pack independently of any GameSage code license. Community packs define
their own terms here.
